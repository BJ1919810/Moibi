# 用户控制闭环最终设计

## 修改原则

用户拥有作品最终控制权，AI只能提出建议。

流程：

用户输入
→ Draft
→ ChangeRequest
→ Impact Analyzer
→ 用户确认
→ Version Commit
→ Ledger / Projection 更新

## 风险分级

低风险：
- 当前章节氛围
- 描写偏好

中风险：
- 角色名字
- 性格
- 人物关系

高风险：
- 身份反转
- 结局改变
- 核心伏笔修改

高风险修改必须重新规划，不允许静默覆盖。

## AI助手权限

AI助手输出建议，不直接写入正式状态。

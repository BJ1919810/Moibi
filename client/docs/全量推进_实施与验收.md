# 墨笔 v2 · 全量推进实施与验收（R4 + R5 + L0）

日期：2026-10-11。定位：在 R3 工程基础上直接落地剩余核心闭环，测试左移；不引入 v1 源码和数据。

## 1. 本轮新增

### R4 · 草稿与正式提交分离

- `server/workflow.js`：章任务独立 JSON 持久化（queued/planning/writing/extracting/needs_input/awaiting_acceptance/committed 等）。生成正文先落入 run.draft，抽取通过后运行 `commitDraft`（纯函数）构造新项目；最后比较 `headVersion`、`editRevision` 进行保存。
- 保存失败不会部分修改正式项目；只有已确认章节进入 `headVersion` 与正式记忆。重大揭示走人工确认路径。
- 支持幂等创建请求、同项目非终态任务互斥、取消、恢复、错过模型返回后显式恢复。工作页面断线不等于取消模型调用。
- 模型调用未知是否已计费时，不自动重发；仅明确排队任务重启时自动恢复。已保存草稿在抽取失败后复用，不强制重写整章。
- `commitDraft` 校验动态状态与人物认知有原文证据；记录正文版本、内容哈希、WriterPacket Manifest；结构校验后推进版本。不存在证据的伏笔回收不能自动认定完成。

### R5 · 受控上下文与轻量 L2

- `server/context-compiler.js`：必选的已授权历史事实，按实体和任务依赖挑选资料；独立必选/可选项预算，不得因超限静默丢弃必选记录。记录 Manifest、引用、估算 token、包哈希及遗漏原因。
- `server/chapter-planner.js`：从当前被授权的数据确定轻量章节任务、必要 fact ID 和风险等级。未批准时 `server/dynamic-plan.js` 使用只含低权限 WriterPacket 的短 JSON L2 细化，并对返回内容做防泄漏检查。
- 作者侧全书梗概/主题不默认流入低权限正文模型；长期记忆仍按事件 ID 和权限规则投影，旧 `legacy_unverified` 不当作正式事实。
- `server/cost.js`：合并全步骤 usage，含可得缓存命中量、输出与思考 token；用户提供单价才折算金额和执行金额预算约束。

### L0 · 创作偏好、改名与篇幅

- `server/author-control.js`：作者偏好卡与版本号，角色名称修改保持稳定实体 ID、记录别名，不覆盖已定稿正文；修改文风和禁止项会使旧版 run 的冻结规划版本过期。
- `server/replan.js`：对章节数变更进行持久化未来规划任务，按 10 章批次，冻结已写章节，禁止直接批准回收秘密；原已确认正文不覆盖。
- `dist/`：无需额外构建的轻量工作台，提供一键创作、偏好更新、改名、任务监看、上下文、恢复、确认和重排。React/Vite 源码仍保留，但本次未验证 React 的新构建。

## 2. 测试左移与结果

- 最先编写的关键失败用例包括：无抽取阻断提交、状态违反前置条件整批回滚、旧版本不覆盖、重复任务不重复写正文、草稿恢复只重试抽取、必选历史超预算阻断、成本上限、规划修订冲突。
- 再补中途取消、晚到的模型异常、首次生成原文泄漏隔离、人物稳定 ID 改名、章节目标重排、已写正文保留以及未来章节引用合法性。
- 本地命令 `node --test`：**154/154 通过，0 fail，0 skipped**。全部使用确定性模型替身；无模型 API 支出。
- 真实数据：保留《十年雨信》既有 34 章大纲与已确认两章；`validateProject` 通过；34 个 WriterPacket 均可编译且未触发当前确定性泄漏规则。这不是 34 章真实生成测试。
- HTTP 冒烟：`/api/health` 200；新静态 JS 200；无授权的跨源请求被 403 拒绝；作品列表可读取。Node 22 环境无需 React 依赖即可启动。

## 3. 重要限制与下一步真实验收

1. **无模型密钥的环境未执行真实付费生成**；未进行十章连续生成、盲评与固定对照组质量实验；不能保证口碑质量、成本净节省百分比或任意创意长期不偏航。
2. 成本熔断金额只有在用户维护符合当前供应商实际价格的计费配置后才生效，且不能预知供应商外部调用 exactly-once；输入估算不能当成实际计费数据。
3. 上下文规则检索和引用证据覆盖已落地，但没有通用语义向量检索；复杂间接因果仍可能漏召回，Manifest 用于可审计而非质量保证。
4. 全量自由文本无法只靠字符串门禁获得强语义安全证明；高风险故事真相仍建议人工确认。
5. 单机 JSON 可以维持 MVP，不能将目录放到共享盘供多个独立 Node 服务进程同时写入。若未来扩展多人、跨机运行，应迁移事务数据库与队列。
6. 前端 npm 依赖拉取在当前执行环境失败，因此交付的 `dist` 是可运行的轻量静态工作台，不声称 React/Vite 已重新编译。`src/` 仅用于后续自行构建。
7. 旧《十年雨信》中没有正文证据的旧事实维持隔离，未擅自当作正式世界事实；迁移和正文原稿均保留。

建议接入真实模型后依次测试：第 3 章草稿—抽取—提交全链路、关闭网页重连、失败恢复、改文风重编译、重排未写章节，最后连续 10 章的固定 A/B 对照与实际费用核算。
